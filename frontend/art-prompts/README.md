# Artes dos cartões de compartilhamento

Fundos em `public/og/art/*.jpg`, gerados com GPT Image (modelo `gpt-image-2.5-sunburst` (versão final; rascunhos no flare),
qualidade high) a partir dos prompts desta pasta. São só arte, sem texto: a logo, o nome,
o placar e os patrocinadores são compostos por cima em `src/lib/og/cards.tsx`.

Retrato: 1024×1536 → redimensionado para 1080×1620 (o cartão 1080×1350 usa a parte de baixo).
Paisagem: 1536×1024 → 1200×800 (o cartão 1200×630 usa a parte de baixo).
